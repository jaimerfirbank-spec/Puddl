Settings

Label position

Show the node name inside the shape or below it.

Size nodes by

Nodes start at the size you picked and grow with the value, so the biggest stand out. Fields only appear here if they hold numbers.

Colour nodes by

Number fields and connections use a pale to dark scale. Text fields give each value its own colour. The Legend fills in automatically. Turn it off to get each node's own colour back.

Map type

Sets the words Puddl uses and which insights show. A network map is people and groups (also called a social or asset map), a systems map is factors that affect each other, a stakeholder map is everyone around one project, an argument map is one claim with the reasons for and against it.

Large map display

Maps with 300 nodes or more get darker nodes, smaller nodes and thinner connections so they stay readable. Simple drawing uses small squares and straight lines from 600 nodes, so very large maps stay smooth.

Map fields

Extra boxes every node on this map has, like Area or Type. They show in the Add/Edit node box and the info panel. Importing a spreadsheet can add them too.

Node Categories

Add, remove, or customize node categories. Changes apply immediately to all existing nodes.

Appearance

Switch between light and dark. This is remembered on this computer.

Background image

Put a picture behind the map, like a street map or a logo. JPG or PNG.

Reset map

Clear every node and connection and start again. You will be asked to confirm.

Connection colours

On: every connection draws in its strength's colour, the same colours as the key on big maps. Off: connections keep their own colours.
